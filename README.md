PlaceMarker - 地图标记与轨迹记录
📱 一款专注于钓点、水库、户外探险的地图应用
功能特点
地图功能
🗺️ 多种地图图层：标准地图/卫星影像/徒步地形/水域钓场/户外探索
📏 比例尺显示：实时显示地图比例
🧭 方向指示：东南西北方向标注（N方向红色高亮）
📍 坐标显示：实时显示地图中心经纬度
📡 GPS定位：实时定位当前位置
📥 离线地图：支持预置钓场区域离线下载
标记功能
点击地图 或 长按地图 添加标记
点击标记按钮 使用地图中心点添加标记
🏷️ 标记分类：普通/钓点/水库/湖泊/河流/景点/营地/停车场
📋 标记管理：查看、编辑、删除标记
轨迹功能
▶️ 开始记录：点击按钮开始记录GPS轨迹
📏 实时距离：记录过程中实时显示移动距离
⏹️ 停止记录：完成轨迹记录并保存
📜 轨迹历史：查看和管理所有轨迹记录
底部导航
地图 / 标记 / 轨迹 三个Tab快速切换
